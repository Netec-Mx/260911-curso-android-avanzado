# Desarrollo de aplicaciones móviles para Sistemas Operativos Android Nivel Avanzado

Este curso avanzado está orientado a desarrolladores Android que ya dominan los fundamentos y desean adquirir las habilidades necesarias para construir aplicaciones modernas, escalables y de alto nivel utilizando exclusivamente Kotlin.

A lo largo de las sesiones, el participante profundizará en conceptos avanzados del desarrollo Android actual, incluyendo corutinas, arquitecturas profesionales (MVVM y Clean Architecture), interfaces declarativas con Jetpack Compose, networking con APIs REST, manejo avanzado de persistencia local, geolocalización, notificaciones, así como el uso de herramientas de Inteligencia Artificial a través de JetBrains AI Assistant para acelerar y optimizar su flujo de trabajo profesional.

El curso culmina con un proyecto final integrador, donde el participante construirá una aplicación completa que combine UI moderna, consumo de servicios, arquitectura, persistencia y capacidades del dispositivo —siguiendo buenas prácticas y estándares actuales de la industria.

## Estructura

## Lista de laboratorios

### Capítulo 1

- [4. Práctica 1. Práctica](Capitulo01/README.md#4-práctica-1-práctica)
  - Descripción: Desarrollar una práctica aplicada sobre Kotlin Multiplataforma (KMP) avanzado y corrutinas, utilizando los conceptos de Kotlin moderno, funciones de orden superior, clases selladas, programación funcional, corrutinas, Flows, Dispatchers y cancelación tratados en el capítulo.
  - Duración estimada: 216 min

### Capítulo 2

- [4. Práctica 2. Práctica](Capitulo02/README.md#4-práctica-2-práctica)
  - Descripción: Construir una interfaz Android moderna con Jetpack Compose que integre composables básicos, manejo de estado, State Hoisting, recomposición, navegación declarativa, Material 3 y listas dinámicas con LazyColumn.
  - Duración estimada: 288 min

### Capítulo 3

- [4. Práctica 3. Práctica](Capitulo03/README.md#4-práctica-3-práctica)
  - Descripción: Implementar una práctica de arquitectura Android basada en MVVM y Clean Architecture, integrando ViewModel, corutinas, StateFlow, Repository, Use Cases, fundamentos de Hilt y manejo de eventos, estados y errores de UI.
  - Duración estimada: 216 min

### Capítulo 4

- [10. Práctica 4. Práctica](Capitulo04/README.md#10-práctica-4-práctica)
  - Descripción: Desarrollar una práctica de consumo de APIs REST mediante Retrofit y OkHttp, incluyendo operaciones GET y POST, autenticación básica, serialización JSON, interceptores, logs, timeouts, manejo de errores con Flow y corutinas y estados Loading / Success / Error.
  - Duración estimada: 216 min

### Capítulo 5

- [4. Práctica 5. Práctica](Capitulo05/README.md#4-práctica-5-práctica)
  - Descripción: Implementar una solución de persistencia local avanzada con Room y DataStore, considerando entidades, DAO, migraciones, consultas, relaciones, Live Paging, estrategias offline-first y un repositorio híbrido que combine API y Room.
  - Duración estimada: 216 min

### Capítulo 6

- [4. Práctica 6. Práctica](Capitulo06/README.md#4-práctica-6-práctica)
  - Descripción: Desarrollar una práctica de integración de servicios del dispositivo que contemple permisos sensibles, obtención de ubicación con FusedLocationProvider, mapas y sensores básicos del dispositivo.
  - Duración estimada: 144 min

### Capítulo 7

- [4. Práctica 7. Práctica](Capitulo07/README.md#4-práctica-7-práctica)
  - Descripción: Construir el proyecto final integrador combinando una UI completa con Compose, arquitectura MVVM y repositorios, consumo de API REST con Retrofit, persistencia con Room o DataStore, manejo de estado con Flows, geolocalización básica y, de forma opcional, JetBrains AI Assistant para optimizar código, generar funciones, sugerir arquitectura y mejorar documentación.
  - Duración estimada: 144 min
